Реализованные тесты
	1.	Добавление книги в словарь books_genre
Метод: add_new_book
ОР: Книга появляется в словаре после добавления.
	2.	Книга не добавляется, если название длиннее 40 символов
Метод: add_new_book
ОР: Книга с длинным названием не добавляется в словарь books_genre.
	3.	Книга не добавляется повторно
Метод: add_new_book
ОР: При повторной попытке добавить одну и ту же книгу, она добавляется только один раз.
	4.	Присвоение допустимого жанра книге
Метод: set_book_genre
ОР: Книге присваивается корректный жанр из разрешённого списка.
	5.	Получение списка книг по жанру
Метод: get_books_with_specific_genre
ОР: Метод возвращает список книг, которым установлен нужный жанр.
	6.	Исключение книг с возрастными ограничениями из списка для детей
Метод: get_books_for_children
ОР: Метод возвращает только те книги, жанр которых не имеет возрастных ограничений.
	7.	Добавление книги в избранное
Метод: add_book_in_favorites
ОР: Книга добавляется в список favorites, если она есть в books_genre.
	8.	Книга не добавляется в избранное повторно
Метод: add_book_in_favorites
ОР: Книга не дублируется в списке favorites.
	9.	Удаление книги из избранного
Метод: delete_book_from_favorites
ОР: Книга удаляется из списка favorites, если ранее была туда добавлена.
